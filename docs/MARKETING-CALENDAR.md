# Marketing calendar workflow

GitHub Projects has a **Roadmap** timeline, not a native monthly calendar grid.

## Project fields
- Category: Marketing or SEO
- Marketing Channel: Facebook, Instagram, TikTok, Email, Blog, Google Ads, Website
- Publish Date: planned publication
- Due Date: internal creative / approval deadline
- Campaign: optional shared campaign name
- Status: Backlog → To Do → In Progress → For Review → Done

## Saved views
- **Marketing & SEO**: board for execution
- **Marketing Schedule**: roadmap filtered to marketing work and configured around Publish Date

Create one issue for each deliverable (post, reel, newsletter, landing page, blog article, or advertising creative). For multi-day campaigns, consider adding Start Date / End Date fields.

## Example issue
Title: `[Marketing] Instagram carousel — outdoor dining feature`

The issue form records the brief and checklist; configure the Publish Date and Channel separately in the Project.

## Weekly routine
1. Review the next two weeks of content.
2. Assign creative owners and approval dates.
3. Move prepared posts to For Review.
4. Approve and schedule.
5. Mark Done after publishing and record results.

For an actual month-by-month grid, connect or build an external calendar. Don't treat the Roadmap as one.
